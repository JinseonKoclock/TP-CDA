L'objectif de ce dépôt n'est pas uniquement de conserver des notes de cours.

Il s'agit de construire progressivement une véritable base de connaissances personnelle, réutilisable pour :

- la préparation du TP CDA ;
- les entretiens techniques ;
- les projets personnels ;
- la poursuite de ma carrière de développeuse.
